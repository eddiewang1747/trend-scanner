# Trend Scanner · 美股趋势感知模型

作为 2560 战法系统的**上游过滤器**——先确定钱在往哪走，再决定买什么。

## 模型逻辑（三层漏斗）

```
第一层: 宏观资金趋势
   ↓ 30+ 个行业/主题 ETF 综合打分
   ↓ 动量(40) + 结构(30) + 量能(15) + RS vs SPY(15)
   ↓ ≥75 强势  |  50-74 形成中  |  <50 弱势
   
第二层: 板块龙头股一致性
   ↓ 检验候选板块内 5 只龙头是否同步走强
   ↓ ≥60% 龙头同步 = 趋势确认
   
第三层: 个股观察名单
   ↓ Minervini Stage 2 + 高分综合筛选
   ↓ 导出 CSV → 喂给你的 2560 扫描器
```

## 运行方式

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动 dashboard
streamlit run app.py

# 浏览器自动打开 http://localhost:8501
```

## 使用流程（建议每周日跑一次）

1. **打开 Tab 1** → 等扫描完成（30-60s），看哪些板块 ≥75 分
2. **跳到 Tab 4 热力图** → 重点看"拐点信号"象限（左上），这是最早期的趋势
3. **回到 Tab 2** → 对前 3 个强势板块做龙头一致性验证
4. **去 Tab 3** → 导出最终观察名单 CSV
5. **把 CSV 喂给你的 2560 系统** → 跑 MA25/VMA5/VMA60 信号

## 评分体系详解

| 类别 | 满分 | 检查项 |
|------|------|--------|
| 动量 | 40 | 1W/1M/3M 收益率正负 + 阈值 |
| 结构 | 30 | 价格 vs MA25/50/200 + 多头排列 |
| 量能 | 15 | 近 5 日均量 / 60 日均量 |
| RS | 15 | 相对 SPY 的超额收益 |

## 调整建议

- **保守用户**: 在 sidebar 把最低分数调到 75，只关注强趋势
- **激进用户**: 调到 50，配合 Tab 4 热力图捕捉左上拐点
- **追加 ETF**: 在 `app.py` 顶部的 `THEME_ETFS` 字典里加新代码即可

## 数据局限性提示

- yfinance 是免费源，盘后数据可能延迟
- 不含期权异动数据（需付费源如 Unusual Whales）
- 13F 资金流数据未集成（季度滞后）
- 真正实战可考虑接 Alpha Vantage / Polygon.io API
